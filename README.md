# Proyek Python Pertama

Repositori ini adalah langkah awal saya dalam belajar Python secara serius, berfokus pada praktik terbaik dunia nyata (real-world practices).

## Tujuan
- Menguasai dasar-dasar Python.
- Membiasakan diri dengan workflow profesional (Virtual Environment, Git, dan GitHub).
- Membangun portofolio proyek.

## Teknologi yang Digunakan
- Python 3.15
- Git & GitHub
- VS Code

## Cara Menjalankan
1. Clone repositori ini: `git clone https://github.com/nabilthaqif-dev/proyek-python-pertama.git`
2. Buat virtual environment: `python -m venv venv`
3. Aktifkan venv (Windows): `venv\Scripts\activate`
4. Jalankan file: `python main.py`
